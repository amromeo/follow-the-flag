<p className="eyebrow">What is interface translation?</p>

### Different systems can use different codes for the same clinical meaning.

An interface translation rule converts a value used by the sending LIS into the
corresponding value expected by the receiving EHR. Here, the LIS sends `CH` and
`CL`, while the EHR recognizes `HH` and `LL`. The result value is not changed—only
the coded interpretation that travels with it.

<p className="role-note">
  An LIS analyst or interface specialist typically configures and tests this
  rule. A laboratory director reviews the clinical meaning, confirms that the
  test set is adequate, and participates in approval according to local
  change-control policy.
</p>
